# Navigating Weaverse Studio

Weaverse Studio is the visual workspace for editing a Hydrogen storefront. The 2026 interface organizes work around page context in the top bar, structure and history on the left, a browser-style live preview in the center, and settings on the right.

![Weaverse Studio with a Hydrogen storefront preview and editing controls](https://cdn.shopify.com/s/files/1/0838/0052/3057/files/weaverse_studio_loaded_2.webp?v=1755078650)

## Top bar

- **Unified page search:** Find pages across Homepage, Product, Collection, Page, Blog, Article, and Custom Page groups.
- **Page and template context:** See the active page or shared/custom template and manage assignments where supported.
- **Locale:** Switch the market or language whose content you are editing.
- **Store URL tabs:** Move between configured storefront contexts without losing the current project.
- **Save and publish:** Commit the current session draft and publish it when ready. See [Saving, Publishing, and History](/studio-guide/saving-publishing-history).
- **Studio settings:** Open preferences, project details, activity, and related workspace controls.

<Warning>
  Page, template, and locale form one editing context. Confirm all three before changing content, restoring history, or assigning a template.
</Warning>

## Left sidebar

### Page Outline

- Select an item to highlight it in the canvas and open its inspector.
- Drag an item to reorder it within an allowed parent.
- Add sections from the components registered by the Hydrogen theme.
- Duplicate, hide, show, or delete items when those actions are available.
- Expand nested items to understand the component hierarchy.

If an outline item exists but cannot be detected in the preview, Studio displays a detectability warning. The section's root DOM element must receive its Weaverse props and `ref`. See [Component Not Selectable](/troubleshooting/component-not-selectable).

### Version History

Version History lives in the left sidebar. Use it to inspect prior saved versions and restore the intended page revision. Restores remain associated with the current page; always verify page and locale before confirming.

## Preview canvas and browser bar

The canvas renders the connected storefront rather than a separate approximation of it.

- Click a visible component to select the matching outline item.
- Use desktop, tablet, and mobile widths to review responsive behavior.
- Navigate with the browser-style URL bar when testing another storefront path.
- Choose among configured preview URLs.
- Review connection status and inline performance signals when available.

When the preview has no editable Weaverse content, Studio distinguishes that state from a disconnected storefront and directs you to the appropriate setup or preview action. See [Managing Previews](/studio-guide/managing-previews).

## Inspector

- **Settings:** Content and behavior declared by the component's `schema.settings`.
- **Style:** Spacing, alignment, colors, backgrounds, borders, and responsive presentation.
- **General actions:** Visibility, duplication, deletion, and related item actions.
- **Theme Settings:** Project-wide settings declared by `themeSchema`, including colors, typography, layout, and PWA configuration.

Resource and URL pickers can search across supported Weaverse pages and Shopify resources. If a picker appears stale, close and reopen it after saving the current selection.

## Editing efficiently

- Use the [keyboard shortcuts guide](/studio-guide/keyboard-shortcuts) for navigation and common editor actions.
- Copy styling from one compatible element and paste it onto another instead of rebuilding the same appearance.
- Keep content changes in the session draft until the logical edit is complete.
- Check responsive widths before saving and publishing.
- Use project backups before broad content restructuring.

## Common workflow

<Steps>
  <Step title="Confirm context">Select the page, template assignment, locale, and preview URL.</Step>
  <Step title="Edit">Select or add a component, then update its content and styles in the Inspector.</Step>
  <Step title="Review">Check the outline, responsive previews, links, product/resource selections, and storefront behavior.</Step>
  <Step title="Save">Commit the session draft and resolve any specific save error Studio reports.</Step>
  <Step title="Publish">Publish the saved version when it is ready for the connected live storefront.</Step>
</Steps>
