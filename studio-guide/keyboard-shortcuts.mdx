# Keyboard Shortcuts

Studio includes an in-product keyboard shortcut reference. Open it from the workspace help or shortcuts action to see the bindings for your current platform and editor context.

<Note>
  Use the in-product reference as the source of truth for exact key combinations. Bindings may differ between macOS and Windows/Linux and can evolve independently of this documentation.
</Note>

## Shortcut categories

The shortcut guide groups actions for moving around the editor, navigating the Page Outline, copying/pasting/duplicating/deleting, undo and redo, saving, and opening workspace tools.

## Safe keyboard editing

- Confirm the selected outline item before duplicate or delete actions.
- Remember that text-field shortcuts apply to text while the cursor is inside an input.
- Save after completing a logical group of changes.
- Check page, template, and locale before saving or publishing.
- Use the confirmation dialog for irreversible actions.

## Copy and paste styling

1. Select the source element.
2. Use the styling copy action shown in the shortcut guide or element menu.
3. Select a compatible destination element.
4. Paste the styling.
5. Review desktop, tablet, and mobile results before saving.

Content and resource selections are not necessarily part of a style-only operation. Verify the destination inspector after pasting.
