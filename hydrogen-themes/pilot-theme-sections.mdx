# Pilot Sections

Pilot sections are React components registered in `app/weaverse/components.ts`. Their schemas determine where they can be added and which settings merchants see in Weaverse Studio.

<Note>
  This inventory tracks Pilot through [`v2026.7.28`](https://github.com/Weaverse/pilot/releases/tag/v2026.7.28). The repository's [`app/sections`](https://github.com/Weaverse/pilot/tree/main/app/sections) directory is the source of truth for newer releases.
</Note>

## Marketing and storytelling

| Section | Primary use | Notable settings |
|---|---|---|
| Hero Image | Image-led campaign or page introduction | Height, content position, background fit, overlay, headings, text, buttons |
| Hero Video | Video-led campaign or brand story | Responsive height, content position, cover behavior, playback controls, hover fade, overlay |
| Slideshow | Multiple promotional slides | Loop, autoplay, arrow shapes, pagination-dot styles, per-slide media and content |
| Image with Text | Two-column editorial content | Image ratio and width, content alignment, spacing, background, text and buttons |
| Image Gallery | Editorial image grid | Item height, gap, column span, radius, mobile visibility |
| Columns with Images | Feature or benefit cards | Column count, images, text, optional links and responsive layout |
| Promotion Grid | Campaign cards in a grid | Grid size, per-card background and overlay, content position, buttons |
| Hotspots | Shoppable image annotations | Hotspot position, icon style and size, selected product, price and details link |
| Countdown | Timed promotion or launch | Start/end time, background, overlay, supporting content and CTA |
| Testimonials | Customer quotes and social proof | Item gap, author image and details, background and content controls |
| Our Team | Team-member profiles | Portrait, name, role, bio, link and responsive layout |
| Video Embed | Embedded third-party video | Video URL, aspect ratio, width and supporting content |
| Map | Store location and contact details | Address, opening hours, description, map and button styles |
| Spacer | Intentional responsive whitespace | Desktop/mobile height and background options |

The **Spacer** section was added in `v2026.7.28`. Prefer it when merchants need editable space between sections; use section padding when the spacing belongs to a single component.

Recent Pilot releases added or refined:

- Sticky add-to-cart and Buy Now controls on product templates.
- Sticky product media for slider layouts.
- Loaded/total collection product counts.
- Scroll arrows and snap behavior for swimlanes.
- Better placeholder handling when quick-shop products have no media.
- Custom-page SEO and sitemap integration.

## Forms and integrations

| Section | Primary use | Requirements |
|---|---|---|
| Newsletter | Email signup | Configure the selected provider or storefront action; supports input and button text/layout controls |
| Judge.me Reviews | Product ratings and reviews | Judge.me credentials and product-route data |
| Ali Reviews | Legacy Ali Reviews rendering | Ali Reviews configuration; confirm the integration is still required before enabling in a new build |

Pilot's footer also supports a Klaviyo newsletter form and configurable input width. Store private API credentials in environment variables—never in section schema defaults or browser code.

## Product purchase experience

Pilot `v2026.7.28` opens the cart drawer immediately when add-to-cart is submitted. It stages the optimistic line locally and displays price skeletons until Shopify confirms the cart response. This behavior belongs to Pilot's shared cart architecture rather than to an independently addable section.

When customizing product sections:

- Preserve cart-line identity returned by Shopify.
- Use the shared optimistic cart modules instead of maintaining a second item count.
- Test quantity changes, removal, cart notes, and checkout totals.
- Keep Buy Now separate from Add to Cart so merchants can enable either action intentionally.

## Hero Video and Slideshow changes

The older section guide described only basic video height and slideshow autoplay. Current Pilot also supports:

- Hero Video content positioning, playback controls, cover sizing, hover fade, and responsive spacing.
- Slideshow arrow-shape choices and pagination-dot styles.
- Semantic heading tags while preserving visual typography.

If upgrading a customized copy, compare section schema changes as well as JSX. New schema defaults do not automatically appear in previously saved component data unless the renderer supplies defaults.

## Add a custom section

Use the React 19 component pattern and register the module:

```tsx
import {
  createSchema,
  type HydrogenComponentProps,
} from '@weaverse/hydrogen';

interface AnnouncementProps extends HydrogenComponentProps {
  ref: React.Ref<HTMLElement>;
  text: string;
}

export default function Announcement({ ref, text, ...rest }: AnnouncementProps) {
  return (
    <aside ref={ref} {...rest}>
      {text}
    </aside>
  );
}

export const schema = createSchema({
  type: 'announcement',
  title: 'Announcement',
  settings: [
    {
      group: 'Content',
      inputs: [{ type: 'text', name: 'text', label: 'Text' }],
    },
  ],
});
```

```tsx
// app/weaverse/components.ts
import * as Announcement from '~/sections/announcement';

export const components = [
  // Existing Pilot sections...
  Announcement,
];
```

<Warning>
  The root DOM element must receive both `ref` and the remaining `HydrogenComponentProps`. If it does not, Studio may show the component in the outline but be unable to detect or select it in the preview.
</Warning>
