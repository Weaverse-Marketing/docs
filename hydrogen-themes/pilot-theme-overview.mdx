# Pilot

Pilot is Weaverse's production-ready Shopify Hydrogen theme. It combines React Router, Hydrogen, and Weaverse Studio so developers retain a version-controlled storefront while merchants edit page structure and content visually.

<Note>
  This guide tracks Pilot through [`v2026.7.28`](https://github.com/Weaverse/pilot/releases/tag/v2026.7.28). If your project was created from an older tag, review [Upgrading Pilot](/hydrogen-themes/pilot-upgrading) before copying individual files or dependency versions.
</Note>

| Tailwind CSS | v4 |
| Swiper | v14 |
| Formatting and linting | Biome `2.5.5` |

Swiper 14 raises the storefront browser baseline to Chrome/Edge 110+, Firefox 110+, and Safari/iOS 16.4+.

## What Pilot includes

### Storefront foundation

- React Router 7 routes, SSR, streaming, and route loaders.
- Shopify Hydrogen on Oxygen, plus Vercel-compatible deployment.
- Strict TypeScript, Storefront GraphQL code generation, Tailwind CSS 4, Radix UI, and Biome.
- Responsive image, carousel, accessibility, SEO, analytics, and localization patterns.
- Playwright end-to-end coverage and focused cart correctness tests.

### Commerce

- Predictive search, optimistic cart state, cart notes, checkout, and analytics.
- Instant add-to-cart drawer with staged optimistic line items.
- Customer Account API authentication and account pages.
- Shopify Markets, multiple language variants per country, and localized URLs.
- Combined Listings and product-bundle support.
- Product and collection templates, related content, quick shop, sticky add-to-cart, and Buy Now options.

### Integrations

- Judge.me reviews.
- Klaviyo newsletter and contact flows.
- Shopify Inbox chat.
- Content Security Policy helpers for Studio and third-party services.

### Installable mobile app

Pilot can expose the storefront as an installable PWA. Enable **Mobile app (PWA)** in Theme Settings to generate a merchant-specific manifest, install prompts, and a whitelist-only service worker. HTML, cart, account, and checkout requests are never intercepted.

See [Installable Mobile App](/features/mobile-app-pwa) for configuration and caching behavior.

## Start a project

<Tabs>
  <Tab title="AI coding agent">
    Install the Weaverse Shopify Hydrogen skills, then ask the agent to run the setup workflow:

    ```bash
    npx skills add Weaverse/shopify-hydrogen-skills
    ```

    The setup starts against bundled demo data, verifies a storefront at `http://localhost:3456`, and then helps connect your Shopify store and Weaverse project.
  </Tab>
  <Tab title="Weaverse Studio">
    1. Install the Weaverse Hydrogen Customizer from the Shopify App Store.
    2. Create a Hydrogen storefront and choose Pilot.
    3. Copy the generated CLI command or agent prompt.
    4. Open the local preview in Studio and begin editing.
  </Tab>
  <Tab title="Clone Pilot">
    ```bash
    git clone https://github.com/Weaverse/pilot my-storefront
    cd my-storefront
    cp .env.example .env
    npm install
    npm run dev
    ```

    The repository's demo environment lets the storefront boot before you replace values with your own Shopify and Weaverse credentials.
  </Tab>
</Tabs>

## Project structure

```text
app/
├── .server/       # Server context, sessions, and Weaverse client
├── components/    # Reusable storefront components
├── graphql/       # Queries and fragments
├── hooks/         # Shared React hooks
├── routes/        # Locale-aware React Router routes
├── sections/      # Weaverse-editable sections
├── styles/        # Tailwind theme, utilities, and keyframes
├── utils/         # Storefront helpers
└── weaverse/      # Component registry, theme schema, and rendering root
```

Important root files include `AGENTS.md`, `react-router.config.ts`, `vite.config.ts`, `codegen.ts`, `biome.json`, and `package.json`.

## Load and render a page

Load Weaverse content in parallel with Shopify data:

```tsx
import type { LoaderFunctionArgs } from 'react-router';

export async function loader({ context }: LoaderFunctionArgs) {
  const { storefront, weaverse } = context;
  const [weaverseData, { shop }] = await Promise.all([
    weaverse.loadPage({ type: 'INDEX' }),
    storefront.query(SHOP_QUERY),
  ]);

  return { weaverseData, shop };
}
```

Render the registered component tree with `WeaverseContent`:

```tsx
import { WeaverseContent } from '~/weaverse';

export default function Homepage() {
  return <WeaverseContent />;
}
```

## Create a React 19 section

All Weaverse sections must extend `HydrogenComponentProps`, accept `ref`, and pass the ref and remaining props to their root DOM element.

```tsx
import {
  createSchema,
  type HydrogenComponentProps,
} from '@weaverse/hydrogen';

interface VideoProps extends HydrogenComponentProps {
  ref: React.Ref<HTMLElement>;
  heading: string;
  videoUrl: string;
}

export default function Video({ ref, heading, videoUrl, ...rest }: VideoProps) {
  return (
    <section ref={ref} {...rest}>
      <h2>{heading}</h2>
      <iframe src={videoUrl} title="Video" allowFullScreen />
    </section>
  );
}

export const schema = createSchema({
  type: 'video',
  title: 'Video',
  settings: [
    {
      group: 'Video',
      inputs: [
        { type: 'text', name: 'heading', label: 'Heading' },
        { type: 'text', name: 'videoUrl', label: 'Video URL' },
      ],
    },
  ],
});
```

Existing `forwardRef` components remain compatible, but React 19 function components are the current Pilot pattern.
